# Чернови (публични)

Черновите на Lexify, които трябва да се отварят с публичен линк — статии и
страници за преглед, преди да влязат в сайта. Всеки HTML файл тук е на адрес

```
https://mihailpp99.github.io/chernovi/<път до файла>
```

около минута след push (GitHub Pages, клон `main`, корен).

⚠️ **Всичко тук е публично, включително старите версии в историята на git.**
Само неща, които всеки може да види: без лични данни, вътрешни бележки и
нерешени цени. Изтрит файл остава в историята.

- Всяка страница носи `<meta name="robots" content="noindex">`, затова не
  влиза в търсачките. `robots.txt` тук не помага: търсачките го четат само
  от корена на домейна (`mihailpp99.github.io`).
- `.nojekyll`: GitHub отдава файловете такива, каквито са, без Jekyll.
- Изходниците са в `../бизнес/` (напр. `Маркетинг/Продукти/a1a2/statia-taen-liyd/`);
  тук е само готовият HTML.
